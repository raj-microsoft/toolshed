How this was made

An interactive take on “15 Free Google AI Tools”, credited in the AI Web Design Library to Amir Afridi + 2 more. The source does not identify the other contributors.

The guide is a reference table, not a build tutorial: its 15 names, one-liners and categories became this working picker. Broad filter groups and keyword rules are editorial. No AI service was used at runtime; plain HTML, CSS and JavaScript do the matching and hook-swing motion. No paid-service substitution was needed.

# The Toolshed
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by brief: plain HTML, CSS and JavaScript; static GitHub Pages from /docs.
## Users
Assumption from the assigned brief: curious makers choosing a Google AI tool for a specific job.
## Product Purpose
Turn the supplied 15-tool reference table into a useful local keyword-based picker, with category filtering, one-line descriptions and official links.
## Constraints
Exactly the guide's 15 entries; no invented capabilities or pricing. No APIs, sign-ups or keys. No user text leaves the browser. Public-safe original assets. Responsive at 390px and desktop; reduced-motion support.
## Brand Commitments
The Toolshed: physical-feeling pegboard, tools hanging on hooks, matching tools swinging forward. This direction is explicitly pinned by the assignment.
## Evidence
Guide 03, “15 Free Google AI Tools,” library credit “Amir Afridi + 2 more.” Source Notion table and the tools' official public pages. Free is the guide title, not a guarantee of current pricing.
## Assumptions
Subagent brief supplies purpose, concept, deployment and delegated stack choice; no independent user interview was available. Card groups and matching keywords are editorial navigation, not provider classifications.
